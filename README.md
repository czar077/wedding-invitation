# শামসিল আরেফিন খান & উম্মে হালিমা (জিনিয়া) — Wedding Invitation

Final personalized digital wedding invitation based on the uploaded printed invitation card.

Included:
- Animated envelope opening
- Printed-card visual theme
- Couple names
- অনুষ্ঠানসূচি
- Wedding countdown to 21 October 2026, 7:00 PM (Bangladesh time)
- Actual invitation card images
- Google Maps button for the wedding venue
- WhatsApp RSVP button

Gaye Holud venue was not supplied, so it is shown as "স্থান পরবর্তীতে জানানো হবে".
